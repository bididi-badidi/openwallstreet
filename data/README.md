# Local research data

This directory holds local collector runs, source snapshots, and derived evidence. Its contents are ignored except for this guide. Preserve original evidence and provenance when working here.

Small curated public examples belong in `src/web/data/` or `src/web/public/` after review. Historical selection inventories live in `docs/archive/alphabet/reviews/`. See [repository hygiene](../docs/repository-layout.md).
