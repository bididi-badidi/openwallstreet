# Inherited maintenance scripts

These scripts are retained from the upstream financial-services reference library for provenance. They are not application tooling or part of CI. Their original assumptions include a different repository root and the full plugin library; do not run them from this archive without adapting those assumptions.

Use [the development guide](../../docs/development.md) for OpenWallstreet checks. Inactive upstream workflows are kept under `docs/archive/upstream/workflows/`.
